## 二A早期探针专项

仅使用固定制造客户场景的合成资料。`scripts/probe_presales_retrieval.py`保存10个开发样例草案，五类各两例：完整、冲突、缺证据/不支持、关键风险、澄清/范围调整。不创建或读取20个冻结验收样例，不将新草案写成已批准黄金数据集。脚本校验固定类别/唯一身份；执行前需记录实际模型、端点、维度及样例摘要，若输入或配置缺失则拒绝执行并记录，不静默切换Fake。

语料为5份合成文档、20个独立段落（含15段干扰材料），超过前8条返回上限。每例检查相关来源及其中的具体预期段落，而非只检查文档曾经出现在结果中；不得用“语料少于8条所以全部返回”冒充检索表现。本轮尚未进行真实Embedding推理，此准备完善不是根据真实结果调优。

第一步只对已有兼容API的`/models`进行至多一次只读发现，不提交业务材料，不根据模型名假定兼容性。发现结果只帮助确定是否存在Embedding/Reranker，不算真实检索探针，也不猜测未配置的付费模型。业务探针仅在显式售前Embedding配置就绪且与批准接收端一致后通过`--execute`执行。

真实探针最多20次Embedding请求、累计12,000输入Unicode字符、600秒；每次请求最多60秒，索引技术重试继续消耗同一计数和字符预算。仅合成类别允许外发；禁重定向、禁继承代理、禁正文观测。精排若未配置，明确报告RRF降级和缺口，不把未运行精排写成通过。实际费用在供应方未提供可信计价/用量时记“未知”，请求/字符预算不能冒充货币扣费保证。运行不得自动扩大请求数或更换端点。

通过同一业务服务登记、解析、构建并由两个不同主体发布合成知识，再用真实Embedding检索，保留每个样例的命中来源、定位、差例、错误、降级和模式。脚本只在显式一次性临时数据库内执行，不对已有业务库初始化/授权/发布。首次样例出现基本链路不可运行或硬门禁失败，应停止依赖推进并报告；语义差距保留后允许已授权工程继续。不得把局部命中率写成P07冻结门槛已通过。

## 本机执行口径

Windows售前HTTP需要使用锁定uvicorn的自定义loop factory，以匹配psycopg的Selector要求：设置进程级`PYTHONPATH=src`后运行`uv run --no-sync uvicorn presales.asgi:app --loop presales.application.workbench:selector_loop_factory`。stdio入口为`uv run --no-sync python -m presales.infrastructure.product_catalog`；两者从显式环境读取售前配置，不自动提升通用聊天配置为Embedding授权配置。

`scripts/test_presales_postgres.py --workbench`是单独的20分钟合成浏览器检查档，不延长现有pytest的180秒超时，不改变默认离线配置。该档仅临时回环实例，结束后停止实例；到时退出不推断通过。生产静态资源/Compose及Linux部署仍不在本轮范围。
